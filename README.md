# Thai Trip Planner (Android)

แอปวางแผนเที่ยวไทยทีละ 1 ทริป สำหรับนักท่องเที่ยวชาวไทยและต่างชาติ (ไทย/อังกฤษ)

## สิ่งที่ทำได้ในเวอร์ชัน 0.1
1. **คลังสถานที่ 25 แห่ง** พร้อมเทศกาล/ช่วงที่แนะนำและเหตุผล รูปภาพเสรีจาก Wikimedia Commons แสดงชื่อผู้ถ่ายและสัญญาอนุญาตทุกภาพ
2. **เลือกวันในปฏิทิน** (ไม่ต้องติดกัน) และเรียงลำดับเอง ตรวจวันซ้อน ถามว่าช่วงว่างใช้ทำอะไร (งาน เยี่ยมญาติ ฯลฯ)
3. **คำเตือน** ความเสี่ยงตามฤดูกาล (หมอกควัน ฝน น้ำป่า ดินถล่ม คลื่นลม อุทยานปิด) + ข้อมูลสด PM2.5 (Air4Thai หรือแบบจำลอง CAMS ผ่าน Open-Meteo) พยากรณ์ฝน/ร้อน/ลม และระดับน้ำแม่น้ำ (Open-Meteo) จุดความร้อน 24 ชม. (NASA FIRMS) ไม่ต้องใส่ key
4. **ที่พัก** ลิงก์ Booking.com / Agoda / Google Maps ตามวันเช็กอิน-เอาต์ และรายการที่พักใกล้เคียง (OpenStreetMap)
5. **การเดินทาง** เลือกจุดเริ่มต้น (สนามบิน สถานีขนส่ง สถานีรถไฟ ท่าเรือ 50 จุด) ตัวเลือกการเดินทางแต่ละช่วง จุดหมายสุดท้าย และลิงก์/เบอร์โทรสำหรับจองหรือตรวจเที่ยว
6. **สรุปทริป** ตั้งแต่จุดเริ่มต้นถึงจุดสุดท้าย พร้อมร้านอาหาร/กาแฟ โรงพยาบาล สถานีตำรวจ และเบอร์ฉุกเฉิน
7. **Activate travel plan** ใช้ GPS + ปฏิทิน แสดงเส้นทางความคืบหน้า และฉากแอนิเมชันตามรูปแบบการเดินทาง (เครื่องบินเหนือเมฆ / รถไฟผ่านภูเขา / รถบัสบนทางหลวง / เรือหางยาวกลางเกาะหินปูน / รถตู้) แตะสถานที่เพื่อเปิดเมนู 3 รายการ
8. **เช็กอิน 10.00 น.** ทุกวัน (ปรับเวลาได้) ถ้าไม่ตามแผนเลือกปรับเฉพาะส่วน หรือเริ่มใหม่
9. **ตอนจบทริป** สไลด์โชว์แบบ morph + เพลงสไตล์ไทยเดิมที่สังเคราะห์ในเครื่อง (ไม่มีปัญหาลิขสิทธิ์) วนต่อเนื่องไม่สะดุด จนกดปุ่มสิ้นสุดทริปแล้วแอปปิดเอง

10. **อัลบั้มทริป** ระหว่างทริปถามทุกวันว่าจะเก็บภาพไหม ถ้าตอบว่าต้องการ ให้ถ่ายด้วยแอปกล้อง (เปิด GPS) เมื่อกลับมาที่แอปจะแสดงภาพที่ถ่ายตอนสลับออกไปให้เลือก แอปคัดลอกภาพเก็บในโฟลเดอร์ของทริป แยกตามสถานที่ (จากพิกัดในภาพหรือ GPS) และวัน ภาพที่ถ่ายห่างจากสถานที่ในแพลนเกิน 40 กม. หรือไม่มีตำแหน่งจะเพิ่มไม่ได้ ลบภาพได้
11. **วิดีโอสไลด์โชว์ (MP4)** วันสุดท้ายถามว่าจะทำอัลบั้มให้สมบูรณ์ไหม เลือกเพลงรายสถานที่ 6 แนว (ดนตรีท้องถิ่น กล่องดนตรี ฮาร์ป แจ๊ส แซมบ้า ขลุ่ย) × 3 จังหวะ × 3 เพลงที่ต่างกัน (เพลงละ 1 นาที สร้างในเครื่อง วนต่อได้ไม่มีรอยต่อ) แต่ละสถานที่เริ่มด้วยป้ายชื่อตกแต่งแบบไทย → morph เข้าภาพแรก → ภาพถัดไปด้วยเอฟเฟกต์ตามจังหวะ (ช้า=morph, กลาง=ซูมจาง, เร็ว=เลื่อน) → ภาพสุดท้าย fade out พร้อมเพลง → ป้ายชื่อสถานที่ถัดไป ไฟล์บันทึกที่ `trips/<id>/slideshow.mp4` และ Movies/ThaiTrip
12. **ทริปของฉัน** ทุกทริปมีโฟลเดอร์ของตัวเอง (อัลบั้ม + สไลด์โชว์) เปิดดูย้อนหลังได้

13. **อัปเดตข้อมูลทุกวันพุธ** GitHub Actions (`.github/workflows/data.yml`) ตรวจและเผยแพร่ `places.json` / `hubs.json` ขึ้น GitHub Pages ทุกวันพุธ 00.00 น. เวลาไทย (และทุกครั้งที่แก้ไฟล์) แอปเช็กไฟล์ใหม่ตอนเปิด ถ้าไม่มีเน็ตใช้ข้อมูลเดิมในเครื่อง ข้อมูลใหม่มีผลตั้งแต่เปิดแอปครั้งถัดไป

ตัวอย่างเพลง (จังหวะปานกลาง แนวละ 3 เพลง เพลงละ 1 นาที) อยู่ในโฟลเดอร์ `music-samples/`

## เปิด GitHub Pages (ทำครั้งเดียว)

Settings → Pages → Source: **GitHub Actions** แล้วไปที่แท็บ Actions → "Publish trip data" → Run workflow ข้อมูลจะอยู่ที่ https://attasakj-blip.github.io/thai-trip-planner/data/v1/meta.json

## Build
- GitHub Actions (`.github/workflows/android.yml`) จะ build APK ให้ทุกครั้งที่ push ไป `main` ดาวน์โหลดได้ที่แท็บ Actions → Artifacts
- หรือเปิดโฟลเดอร์นี้ด้วย Android Studio แล้วกด Run

## 30 ภาษา
เมนูเลือกได้ 30 ภาษา (ไทย อังกฤษ และอีก 28 ภาษาที่นักท่องเที่ยวต่างชาติใช้มากที่สุด จากสถิติกระทรวงการท่องเที่ยวและกีฬา ปี 2566–2568 รวมตามภาษา): จีนตัวย่อ มลายู ฮินดี รัสเซีย จีนตัวเต็ม เกาหลี เยอรมัน ญี่ปุ่น ลาว เวียดนาม ฝรั่งเศส อินโดนีเซีย อาหรับ ฟิลิปปินส์ พม่า เขมร ดัตช์ สเปน ฮีบรู อิตาลี สวีเดน โปแลนด์ เบงกาลี เดนมาร์ก นอร์เวย์ โปรตุเกส ตุรกี ฟินแลนด์ (อันดับ 27–29 ใกล้เคียงกับเช็กและสิงหล)

- ข้อความไทย/อังกฤษเขียนในโค้ด `tr("ไทย", "English")`
- ภาษาอื่นอยู่ที่ `app/src/main/assets/i18n/<code>.json` (แปลจากข้อความอังกฤษ)
- เมื่อเพิ่มข้อความใหม่ในโค้ด อัปเดต `i18n/source.json` แล้วรัน `python3 i18n/check.py` เพื่อดูว่าภาษาไหนยังขาด
- ชื่อสถานที่และคำอธิบายในคลังข้อมูลยังมีแค่ไทย/อังกฤษ ภาษาอื่นจะเห็นเป็นภาษาอังกฤษ

## แหล่งข้อมูลสด (ฟรีทั้งหมด ไม่ต้องใส่ key)
- PM2.5: Air4Thai (กรมควบคุมมลพิษ) ถ้าเชื่อมต่อไม่ได้ใช้แบบจำลอง CAMS ผ่าน Open-Meteo
- พยากรณ์อากาศ / ระดับน้ำแม่น้ำ (GloFAS): Open-Meteo
- จุดความร้อน: NASA FIRMS ไฟล์สาธารณะ 24 ชม. (VIIRS)
- ร้านอาหาร คาเฟ่ ที่พัก โรงพยาบาล ตำรวจ: OpenStreetMap (Overpass API)

## ยังไม่มี / ทำต่อ
- ฉากบิน 3D ด้วย Google Maps 3D (ต้องมี API key) สำหรับช่วงเดินทางด้วยเครื่องบิน
- ราคาที่พักและห้องว่างแบบเรียลไทม์ (ต้องสมัคร Agoda/Booking partner API)
- ตารางเที่ยวบิน/รถ/เรือแบบเรียลไทม์ (ต้องสมัคร API พาร์ทเนอร์)
- พิกัดจุดขนส่งเป็นค่าประมาณ ควรตรวจสอบภาคสนามก่อนใช้จริง
